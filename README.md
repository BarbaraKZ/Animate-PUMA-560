# Animate-PUMA-560
In this project, the six-degree-of-freedom industrial robot PUMA 560 (Unimate PUMA 560) is investigated.

The geometric information and inertial parameters of this robot have been extracted from a reference paper. The goal of the project is to obtain the forward and inverse kinematics for the first three joints of the robot (without considering the wrist joints), its simulation with the RVC robotics toolbox, and finally, designing a controller for the presented dynamic model in the form of a Simulink file.
